# Gemini 图片批量下载（Chrome 扩展）

[English](README.en.md) | 中文

一键批量下载 [gemini.google.com](https://gemini.google.com) 对话窗口中的图片原图。适用于 **Windows 与 macOS** 的 Chrome / Edge / Brave 等 Chromium 内核浏览器（Chrome 102+）。

## 功能

- 📦 **批量下载**：自动扫描当前对话里的所有图片（✦ AI 生成图 / ↑ 用户上传图 / • 其他），勾选后一键保存
- 📁 **一次选择，整批直存**：默认「选文件夹」模式只在第一次弹一次目录选择框，本批图片全部直接写入该文件夹，并记住它（同一浏览器会话内再次下载不再询问）
- 🖼️ **多通道原图恢复**：自动把页面缩略图地址转换为原图地址（`=d`），并经网络请求记录配对、页面字节转换、原生下载截获等多级通道尽力获取最高画质
- 🖱️ **页面内选图**：弹窗缩略图加载受限时，可直接在 Gemini 页面内的浮层上选图（使用页面已显示的图片，必定可见）
- 📜 **滚动加载**：对话很长时自动逐屏扫掠整个对话，边滚边收集
- 🖱️ **右键下载**：在任意一张图片上右键 →「下载 Gemini 图片原图」
- 📝 **自动命名**：按「对话标题_序号」命名，与已有文件自动去重
- 👁️ **进度与诊断**：进度条 + 分类计数 + 失败原因链，中断后可一键续存

## 安装

### 方式一：从 Releases 下载（推荐）

1. 打开本仓库的 [Releases](../../releases) 页面，下载最新版 `gemini-image-downloader-vX.X.X.zip`
2. 解压到任意目录（解压后的文件夹需要保留，勿删）
3. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
4. 打开右上角「**开发者模式**」开关
5. 点「**加载已解压的扩展程序**」，选择解压出的文件夹
6. （可选）把扩展图标固定到工具栏

### 方式二：从源码加载（开发者）

克隆本仓库后，同样以「加载已解压的扩展程序」选择仓库根目录即可。

> 安装或更新扩展后，请**刷新已打开的 Gemini 页面**。

## 使用

1. 打开一个包含生成图片的 Gemini 对话
2. 点击工具栏扩展图标，弹窗会自动扫描并列出**对话中的所有图片**（默认只勾选生成图）
3. 对话较长时点「**⬇ 滚动加载并扫描**」自动逐屏收集
4. 勾选要下载的图片（点缩略图或序号卡片切换选中，↗ 可预览原图），支持「在页面中选图」
5. 选画质档：**网页图（快）**＝保存页面预览图，瞬时；**原图（完整尺寸）**＝逐张截获完整尺寸，较慢，失败自动落网页图
6. 点「**下载选中**」：
   - **选文件夹，批量直存**（默认）：自动打开批量保存页（新标签页），第一次弹出目录选择框后整批写入并记住位置；状态栏可「更换保存文件夹」
   - **浏览器下载**：走 Chrome 下载流程，保存到「下载/Gemini图片/」

保存页是独立标签页，不受弹窗关闭影响；已保存的文件不会重复下载，中断后可一键续存。

## 工作原理

- **常规情况**：Gemini 页面里的生成图片是 `https://lh3.googleusercontent.com/gg/…=w640-h640` 形式的地址，末尾 `=w…h…` 只是显示尺寸参数，把后缀换成 `=d` 即可取回原始分辨率的文件
- **新版页面**：部分会话的图片是页面内存中的 `blob:` 地址（不落 URL），扩展会经 Gemini 页面自身把字节转出后写盘，缩略图同样经页面转换显示
- **原图恢复**：按「服务器原图地址 → 页面网络请求记录配对 → 原生下载截获 → 页面预览图」多级降级，并对候选原图做宽高比校验与字节大小对比，保证写入的总是能拿到的最佳画质

整个过程纯本地运行：图片 URL 仅用于向 Google 图片服务器直接下载，不收集、不上传任何数据，无任何统计代码。

## 已知限制

- **原图分辨率**：Gemini 新版页面对话图片为页面内存预览图且原图地址不暴露在 DOM 中。扩展会通过多条通道尽力恢复原图，但在部分环境下仍可能只保存到预览图（约几百 KB）。该问题已知，通道仍在持续改进
- 不下载 Veo 生成的**视频**（只处理图片）
- 深度扫描期间页面会自动滚动一遍，完成后恢复原位置
- 单次扫描上限 500 张
- 仅支持 Chromium 内核浏览器（Chrome / Edge / Brave 等），**不支持 Firefox 与 Safari**

## 常见问题

- **弹窗提示「未发现图片」**：确认当前标签页是 gemini.google.com 的对话页且页面里已出现图片；长对话请用「滚动加载并扫描」
- **更新扩展后扫描失败 / 无响应**：刷新 Gemini 页面（内容脚本需要重新注入）
- **「选文件夹」模式没弹目录框**：说明之前已记住文件夹且授权仍有效，会直接开始保存；想换目录点「更换保存文件夹」
- **保存中弹窗被关闭**：不影响——「选文件夹」模式的保存在独立保存页完成；若保存页也中断，下次打开弹窗会显示「上次有 N 张未保存完，点此继续」
- **Gemini 页面改版导致扫不到**：内容脚本依赖 `<model-response>` 等自定义元素标签，改版后可更新 `content.js` 顶部的 `MODEL_TAGS` 适配

## 目录结构

```
gemini-downloader/
├── manifest.json       # MV3 清单
├── lib.js              # 共享工具函数（URL 转换、文件名清洗、原图配对）
├── save-lib.js         # 保存管线共享库（多通道取字节、文件夹去重）
├── content.js          # 内容脚本：扫描对话页图片、深度滚动、页面内选图
├── background.js       # Service Worker：下载队列、右键菜单、角标
├── popup.html/css/js   # 弹窗 UI：扫描、勾选、弹窗内直接保存
├── saver.html/css/js   # 批量保存页（备用）：中断续存时使用
├── icons/              # 扩展图标
├── dev/                # 开发辅助（预览页、图标生成、lint 门禁、诊断扩展）
└── tests/              # node 单元测试（node tests/lib.test.js）
```

## 开发

```bash
node tests/lib.test.js         # 工具函数单元测试
node tests/save-lib.test.js    # 保存管线集成测试（stub chrome/fetch）
bash dev/lint.sh               # 发布前门禁：单测 + 语法 + no-undef
node dev/make_icons.js         # 重新生成图标
```

`dev/preview.html` 与 `dev/panel-preview.html` 可在浏览器中直接打开，预览弹窗与页面内选图面板的布局。
