# Gemini 图片批量下载（Chrome 扩展）

一键批量下载 [gemini.google.com](https://gemini.google.com) 对话窗口中 **AI 生成的图片原图**。

## 功能

- 📦 **批量下载**：自动扫描当前对话里的所有生成图片，勾选后一键保存原图
- 📁 **一次选择，整批直存**：默认「选文件夹」模式只在第一次弹一次目录选择框，本批图片全部直接写入该文件夹，并记住它（同一浏览器会话内再次下载不再询问）；也可切换为浏览器默认下载
- 🖼️ **真原图**：把页面上 `=w640-h640` 这类缩略图地址转换为 `=d` 原图地址（与 Gemini 自带下载按钮一致）
- 🏷️ **自动区分**：✦ 生成图 / ↑ 用户上传图，默认只勾选生成图（可在弹窗里改为包含上传图）
- 📜 **滚动加载**：对话很长时，点「滚动加载并扫描」自动滚到底部触发懒加载再收集
- 🖱️ **右键下载**：在任意一张图片上右键 →「下载 Gemini 图片原图」
- 📝 **自动命名**：按「对话标题_序号」命名，与文件夹内已有文件自动去重（`xx (1).png`）
- 👁️ **下载进度**：弹窗进度条 + 扩展图标角标实时显示

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「**开发者模式**」开关
3. 点左上角「**加载已解压的扩展程序**」，选择本文件夹（`gemini-download`）
4. （可选）把扩展图标固定到工具栏

> Edge 同样适用：`edge://extensions` → 开发者模式 → 加载解压缩的扩展。
> 安装或更新扩展后，请**刷新已打开的 Gemini 页面**。

## 使用

1. 打开一个包含生成图片的 Gemini 对话
2. 点击工具栏扩展图标，弹窗会自动扫描并列出**对话中的所有图片**（✦ 生成图 / ↑ 上传图 / • 其他，默认只勾选生成图）
3. 对话较长时点「**⬇ 滚动加载并扫描**」：从顶部开始逐屏双向扫掠整个对话，边滚边收集懒加载/虚拟化的图片，完成后恢复原位置
4. 勾选要下载的图片（点缩略图或序号卡片切换选中，↗ 可预览原图），支持「在页面中选图」
5. 点「**下载选中**」，全程在弹窗内完成：
   - **选文件夹，批量直存**（默认）：第一次会从弹窗弹出一次「选择文件夹」对话框，之后文件夹被记住，**再下载零对话框**，直接写入同一文件夹。状态栏可随时「更换保存文件夹」
   - **浏览器下载**：走 Chrome 下载流程，保存到「下载/Gemini图片/」。注意：若 Chrome 开启了「下载前询问每个文件的保存位置」，这种方式会逐张弹窗，请改用「选文件夹」模式

### 缩略图无法显示时：页面内选图

Gemini 对生成图片有严格的来源校验，部分环境下扩展弹窗内无法加载缩略图（卡片显示序号）。
此时状态栏会出现「**在页面中选图**」入口：点击后 Gemini 页面右侧会浮出选图面板，
里面是**页面本身已显示的图片**（直接克隆页面元素，必定可见）。点图勾选后：

- 点「**完成并下载**」：按已记住的文件夹直接开始保存（首次需选一次文件夹）
- 点「仅同步到弹窗」：回到扩展弹窗，勾选结果已同步，点「下载选中」完成

保存期间请保持弹窗/保存页打开（点击页面其他位置弹窗会关闭、保存中断）。已保存的文件不会重复下载；
若弹窗意外中断，下次打开会显示「上次有 N 张未保存完，点此继续」，一键续存。

保存链路有三级兜底：弹窗直接抓取 → 扩展后台抓取 → 浏览器下载，尽量保证每一张都能落盘。

## 工作原理

- **常规情况**：Gemini 页面里的生成图片是 `https://lh3.googleusercontent.com/gg/…=w640-h640` 形式的地址，
  末尾 `=w…h…` 只是显示尺寸参数，把后缀换成 `=d` 即可取回**原始分辨率**的文件（类型由服务器决定）。
- **新版页面**：部分会话的图片是页面内存中的 `blob:` 地址（不落 URL）。扩展会经 Gemini 页面自身把字节
  转出后写盘；缩略图同样经页面转换显示。整个过程纯本地，不经过任何第三方服务器。

弹窗缩略图直接复用页面上已加载的缩略图地址；若加载失败，会自动改由扩展后台抓取并转成 data URL 显示。

```
├── manifest.json       # MV3 清单
├── lib.js              # 共享工具函数（URL 转换、文件名清洗等）

├── background.js       # Service Worker：下载队列、抓图兜底、右键菜单、角标
├── popup.html/css/js   # 弹窗 UI：扫描、勾选、弹窗内直接保存

└── tests/              # node 单元测试
```

## 常见问题

- **弹窗提示「未找到图片」**：确认当前标签页是 gemini.google.com 的对话页且页面里已出现图片；长对话请用「滚动加载并扫描」。
- **更新扩展后扫描失败 / 无响应**：刷新 Gemini 页面（内容脚本需要重新注入）。
- **「选文件夹」模式没弹目录框**：说明之前已记住文件夹且授权仍有效，会直接开始保存；想换目录点保存页里的「更换保存文件夹」。浏览器重启后首次保存需重新授权一次（不用重新选目录）。
- **想连用户上传的图一起下载**：勾选弹窗里的「包含用户上传的图片」。
- **下载个别失败**：多为网络抖动，重试即可；扩展会在 `=d` 失败时自动尝试 `=s0` 原尺寸地址。
- **Gemini 页面改版导致扫不到**：内容脚本依赖 `<model-response>` 等自定义元素标签和 `/gg/` URL 特征，改版后可更新 `content.js` 顶部的 `MODEL_TAGS` 适配。

## 已知限制

- 不下载 Veo 生成**视频**（只处理图片）
- 深度扫描期间页面会自动滚动一遍，完成后恢复原位置
- 扫描上限 500 张 / 单次下载

## 隐私

扩展只在本地工作：图片 URL 仅用于向 Google 图片服务器直接下载，不收集、不上传任何数据。
